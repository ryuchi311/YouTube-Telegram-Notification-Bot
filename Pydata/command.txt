📺 YOUTUBE CHANNEL MANAGEMENT COMMANDS

📌 /add_youtube_channel
   ├─ 🎯 Purpose: Add YouTube channel (without Telegram group)
   ├─ 👤 Who can use: Admins only
   ├─ 📝 Usage: /add_youtube_channel [channel_name] [channel_id]
   ├─ 🌟 Example: /add_youtube_channel PewDiePie UC-lHJZR3Gqxm24_Vd_AJ5Yw
   └─ 💡 Tip: Channel will be verified before adding

📌 /add_youtube_channel_with_group
   ├─ 🎯 Purpose: Add YouTube channel WITH Telegram group link
   ├─ 👤 Who can use: Admins only
   ├─ 📝 Usage: /add_youtube_channel_with_group [name] [id] [tg_link]
   ├─ 🌟 Example: /add_youtube_channel_with_group MikeTamago UCR3aArAyYGXwJegyRGZ7WTg https://t.me/tamagowarriors
   ├─ ✨ Special: Creates clickable "Join_MyTG" links in notifications
   └─ 💡 Tip: Telegram link must start with https://t.me/ or t.me/

📌 /remove_youtube_channel
   ├─ 🎯 Purpose: Remove YouTube channel from monitoring
   ├─ 👤 Who can use: Admins only
   ├─ 📝 Usage: /remove_youtube_channel [channel_id]
   ├─ 🌟 Example: /remove_youtube_channel UC-lHJZR3Gqxm24_Vd_AJ5Yw
   └─ 💡 Tip: Use /list_youtube_channels to see channel IDs

📌 /list_youtube_channels
   ├─ 🎯 Purpose: Show all monitored YouTube channels
   ├─ 👤 Who can use: Admins only
   ├─ 📝 Usage: Just type /list_youtube_channels
   └─ 💡 Shows: Channel names, IDs, and Telegram group links

🔍 HOW TO FIND YOUTUBE CHANNEL ID
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔

Method 1: From Channel URL
├─ 🌐 Go to: youtube.com/channel/UC-lHJZR3Gqxm24_Vd_AJ5Yw
├─ 📋 Copy: UC-lHJZR3Gqxm24_Vd_AJ5Yw (the part after /channel/)
└─ ✅ That's your channel ID!

Method 2: From Custom URL
├─ 🌐 Go to: youtube.com/@channelname
├─ 👀 Look for "View channel ID" option
├─ 🖱️ Right-click → View page source
└─ 🔍 Search for: "UC" (channel IDs start with UC)

Method 3: Online Tools
├─ 🔧 Use: commentpicker.com/youtube-channel-id.php
├─ 📝 Paste: Channel URL
└─ ✨ Get: Channel ID instantly

🎯 STEP-BY-STEP SETUP FOR BEGINNERS
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔

STEP 1: 🤖 Test Your Bot
├─ 💬 Send: /start_notify (to check if bot responds)
├─ ❓ Send: /help_notify (to see all commands)
└─ ✅ If bot responds, you're ready to proceed!

STEP 2: 📺 Add Your First YouTube Channel
├─ 🔍 Find the YouTube channel ID (see guide above)
├─ 💬 Send: /add_youtube_channel_with_group ChannelName ChannelID https://t.me/yourgroup
├─ 🌟 Example: /add_youtube_channel_with_group MrBeast UCX6OQ3DkcsbYNE6H8uQQuVA https://t.me/mrbeastfans
└─ ✅ Bot will verify the channel exists

STEP 3: 📱 Set Up Telegram Notifications
├─ ➕ Add bot to your Telegram group/channel
├─ 👑 Make bot an administrator (important!)
├─ 💬 In the group, send: /add_telegram_notify
└─ ✅ Bot will confirm the group is added

STEP 4: 🔍 Verify Your Setup
├─ 💬 Send: /list_youtube_channels (see your channels)
├─ 💬 Send: /list_notify (see your notification groups)
└─ ✅ Everything listed? You're all set!

⚠️ COMMON ISSUES & SOLUTIONS
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔

🚫 "Sorry, only admin users can use this bot"
└─ 💡 Solution: Your Telegram user ID is not in ADMIN_USERS

❌ "Could not find YouTube channel with ID"
└─ 💡 Solution: Double-check the channel ID is correct

🔐 "Chat not found" or "Bot was blocked"
└─ 💡 Solution: Bot will automatically remove invalid chats

⚡ "Network timeout" or connection errors
└─ 💡 Solution: Check internet connection, bot will retry automatically

🚯 Bot not responding at all
├─ 🔍 Check: .env file has correct TELEGRAM_BOT_TOKEN
├─ 🔍 Check: Bot is running (python YT-BOT.py)
└─ 🔍 Check: No errors in terminal output

🏆 PRO TIPS FOR ADVANCED USERS
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔

💡 Tip 1: Organize Your Channels
├─ 📁 Group similar channels together
├─ 🏷️ Use descriptive names when adding channels
└─ 📝 Keep a list of your channel IDs for backup

💡 Tip 2: Optimize Check Intervals
├─ ⚡ CHECK_INTERVAL=300 (5 min) - Good for active channels
├─ 🐌 CHECK_INTERVAL=600 (10 min) - Good for less active channels
└─ ⚠️ Don't go below 60 seconds (API rate limits)

💡 Tip 3: Multiple Notification Groups
├─ 🎯 Different groups for different types of content
├─ 👥 Gaming channels → Gaming group
├─ 🎵 Music channels → Music group
└─ 📚 Educational channels → Learning group

💡 Tip 4: Backup Your Configuration
├─ 💾 Save your .env file
├─ 💾 Backup Pydata/influencers.json
└─ 💾 Backup Pydata/telegram_chats.json
