 Command Reference — YouTube → Telegram Bot

Simple, copy-friendly command list with examples and notes.

Note: Most management commands require an admin user (`ADMIN_USERS` in `.env`).

Basic commands
- /start_notify — Shows a welcome message and basic usage.
- /help_notify — Prints the list of available commands.
- /how_notify — Step-by-step setup guide for beginners.

Notification management (admin only)
- /add_telegram_notify
  - Purpose: Add the current chat or group to receive notifications.
  - Usage: Type it inside the target group (bot must be admin).

- /remove_notify
  - Purpose: Remove the current chat from notifications.
  - Usage: Type it inside the group you want to remove.

- /list_notify
  - Purpose: Show configured chats that will receive notifications.

Pause / resume (admin only)
- /pause_notify — Pause all YouTube notifications temporarily.
- /unpause_notify — Resume notifications.
- /status_notify — Show pause state, channel count, chat count, and interval.

Thumbnails (admin only)
- /enable_thumbnails — Include video thumbnails in notifications.
- /disable_thumbnails — Send text-only notifications with smart link preview (small preview below text).
- /set_link_preview <option> <true|false> — Configure link preview options (settings saved in settings.json)
  Options: is_disabled, prefer_small, prefer_large, show_above
  Example: /set_link_preview prefer_small true

YouTube channel management (admin only)
- /add_youtube_channel <name> <channel_id>
  - Adds a YouTube channel for monitoring (no TG link).
  - Example: /add_youtube_channel PewDiePie UC-lHJZR3Gqxm24_Vd_AJ5Yw

- /add_youtube_channel_with_group <name> <channel_id> <tg_link>
  - Adds a channel with a Telegram group link. Notifications include a clickable "Join_MyTG" link.
  - Example: /add_youtube_channel_with_group MikeTamago UCR3aArAyYGXwJegyRGZ7WTg https://t.me/tamagowarriors

- /remove_youtube_channel <channel_id>
  - Removes a monitored channel.

- /list_youtube_channels
  - Lists all monitored channels with IDs and optional TG links.

Tips for finding a YouTube channel ID
- Look for URLs like `youtube.com/channel/UC...` and copy the `UC...` value.
- For `youtube.com/@username` pages, use online tools or check View Page Source.

Beginner setup (quick)
1. Add bot to your Telegram group and make it admin.
2. In the group, run `/add_telegram_notify`.
3. Add a YouTube channel with `/add_youtube_channel_with_group` (optional tg link).
4. Verify with `/list_youtube_channels` and `/list_notify`.

Common issues
- "Bot not responding": Ensure `.env` has `TELEGRAM_BOT_TOKEN` and bot is running.
- "Chat not found" or "Bot was blocked": The bot will remove invalid chats automatically.
- "Could not find channel": Verify the channel ID is correct.
